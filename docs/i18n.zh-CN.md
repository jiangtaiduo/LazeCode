# 国际化（i18n）

[英文](i18n.md) | 简体中文

原生界面支持英文与简体中文。项目没有 JSON 字典或运行时 key 查表；文案写在调用
处，由当前 `Language` 选择。

## 事实来源

| 位置 | 职责 |
|---|---|
| `lazecode-core::settings::Language` | 持久化设置（`english` / `chinese`） |
| `lazecode-ui::i18n::t` | `(lang, en, zh)` 选择器 |
| `crates/lazecode-ui/src/*` | UI 文案，通常通过 `tr!` |
| `crates/lazecode-app/src/main.rs` | macOS 原生菜单，通过 `pick(zh, en, cn)` |
| `lazecode-core` 的 toast/模型 | 需要双语的动态消息 |

## 使用

```rust
crate::tr!(model, "Save", "保存")
```

`tr!` 展开为 `lazecode_ui::i18n::t(model.settings.language, en, zh)`。请在渲染时
调用，不要把翻译后的 `&str` 缓存在跨语言切换仍存活的结构里。

动态消息在调用处格式化：

```rust
if model.settings.language.is_zh() {
    format!("已打开 {name}")
} else {
    format!("Opened {name}")
}
```

## 新增或修改文案

1. 英文和中文一起加，不能只加一边。
2. 静态 UI 文案用 `tr!`；带参数的动态消息用 `language.is_zh()`。
3. 如果该操作也出现在原生菜单，同步修改 `pick(zh, en, cn)`。
4. 两种语言中的快捷键符号（`⌘`、`⇧`）保持一致。

## 原生菜单

macOS 菜单在第一帧之前构建，无法读取 UI 字典。`main.rs` 通过 `pick(zh, ...)`
选择文案，并在语言变化时重建菜单。因此菜单是第二份镜像，修改工具栏/命令面板
文案时要同步检查。

## 检查

`cargo test --workspace` 覆盖本地化的模型/UI 辅助行为。没有独立的 i18n linter，
因为不存在可漂移的 key 集合；评审时需确认每个新增 `tr!` / `is_zh()` 的两个分支
都存在。
